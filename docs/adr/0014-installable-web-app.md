# ADR 14: Installable web app

Status: accepted, amended by ADR 19 (service worker offline page cache)
and ADR 74 (Web Push, app badge, share target and protocol handlers).

## Context

alborz ships a web app manifest and service worker so it can be
installed on mobile and desktop, start with cached shell assets, receive
live mailbox updates over SSE, and match the active theme's chrome.

## Decision

### Service worker

1. `/sw.js` is generated by the server with digest-stamped asset URLs
   and caches the shell (stylesheets, scripts, icons) cache-first. Page
   caching and offline behaviour follow ADR 19 and ADR 90.

### Live updates

2. Each browser opens one Server-Sent Events stream at `/events`. Events
   carry only an account and mailbox name (`event: mailbox`) or
   `event: locked`, never markup or message content. The page closes the
   stream on `pagehide` and reopens it on `pageshow` so cached pages do
   not hold connections open.
3. On `event: mailbox`, the page refreshes the rail. A visible list for
   that mailbox reloads automatically only when idle at the top of page
   1 with no selection or focused field; otherwise it offers a manual
   refresh banner (`list.mailarrived`).
4. Without JavaScript, a page reflects the state at load time.

### Presentation

5. htmx swaps MUST NOT use view transitions
   (`globalViewTransitions: false`).
6. Bottom-docked elements pad by `env(safe-area-inset-bottom)`.
7. The manifest sets `display: "minimal-ui"`.
8. Every theme stylesheet MUST declare `--theme-color` (light first,
   dark last, or once for a scheme-pinned theme per ADR 48). The server
   reads it at startup and renders `<meta name="theme-color">` tags;
   `scheme.js` (ADR 50) updates which tag applies.
9. The manifest omits `theme_color` so mobile browsers use their native
   light/dark chrome until the page's `<meta name="theme-color">`
   applies, and sets `background_color` to the default light background.

## Consequences

- Translucent top bars (`glass`) declare an opaque `--theme-color`
  approximation.
- `custom.css` does not alter the startup `<meta name="theme-color">`
  values.
