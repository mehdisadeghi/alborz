## Resolved findings

Every repaired behavior had a failing regression before its production change.
The following examples summarize the observed failures and resulting behavior;
the named commands below reproduce the permanent regressions.

| Area | Observed failure before repair | Result after repair |
|---|---|---|
| Authentication trust | Guessed IDs, sibling domains and unverified ARC established verdicts | Explicit, exact configured authserv-id only; suggestions confer no trust |
| Login/session | GET credentials authenticated; removed remembered credentials survived on disk | POST login required; removing the last remembered account deletes its disk record, including across restart |
| Sieve | Custom `alborz` scripts overwritten/deleted; flags followed filing | Exact generated-script ownership checked before mutation; customized/reordered/duplicate includes preserved; flags precede `fileinto` |
| IMAP/SMTP | Localized roles absent; final 451/554 treated as uncertain | SPECIAL-USE requested; explicit DATA rejection retains typed error and releases retry reservation; lost response stays uncertain |
| Mail syntax/lists | Empty `<>` ancestry; signature joined to flowed text; comma-bearing list URIs split | Missing IDs omitted, single In-Reply-To fallback supported; signature boundary and bracket/comment URI parsing preserved |
| One-click unsubscribe | Header signal allowed POST without authenticated header coverage | POST disabled; ordinary link retained until valid DKIM coverage of both list headers can be established |
| Calendar identity | CANCEL for `event-123` deleted `prefix-event-123`; same-path UID replacement returned 201 | Exact lookup plus library UID validation; transactional UID-conflict refusal preserves bytes and indexes |
| Calendar concurrency | Invitation writes/deletes discarded intervening edits | Read ETag required for mutation; create uses If-None-Match `*`; missing/weak stored ETag refuses mutation |
| DAV HTTP conditions | Matching reads returned 200; forbidden DELETE returned 204 | Matching If-None-Match reads return bodyless 304 and DELETE returns 412; predicate order and atomic backend dispatch covered |
| ETag syntax | Quoted commas rejected; backslash tags conflated | Opaque bytes preserved, commas split outside quotes, full malformed lists rejected |
| Remote sync | Page-one update followed by page-two delete resurrected an object | Last operation per name wins before mirror commit/token advancement |
| Alarms | Two-day offsets absent; repeated/absolute alarms missed or duplicated | Trigger-derived windows, source-based absolute identity, bounded repeat-index arithmetic across supported calendar range |
| vCard | First decode split `GEO="geo:12,34"`; next decode corrupted address | Quoted boundaries, literal backslashes and RFC 6868 caret encoding preserved independently of property TEXT escaping |
| DATE recurrence | Berlin spring instance ended at 01:00, autumn at 23:00; late overlaps missed | Calendar-day spans and DATE movements preserve midnight across Berlin and half-hour Lord Howe transitions |
