# ADR 14: Installable web app

Status: accepted. Superseded in part by ADR 19 (the service worker
saves pages for offline reading; `/offline` is removed).

## Context

alborz ships a web app manifest and icons, so a phone can install it.
Installed, it should start from cache, learn of new mail without
polling, and respect the device's edges. Mail stored by the browser
outlives the session and is out of alborz's reach.

## Decision

### Service worker (rules 1-2 superseded by ADR 19)

1. `/sw.js` is generated by the server and names the digest-stamped
   asset URLs. It caches the shell (stylesheet, scripts, icons)
   cache-first; the cache name changes with the asset set.
2. No other response is stored. A failed navigation is answered with
   `/offline`.

### Live updates

3. Each browser opens one Server-Sent Events stream, `/events`. An
   event carries an account and a mailbox name (`event: mailbox`), or
   `event: locked`. It MUST NOT carry markup or message content.
4. On an event a page refreshes the rail. A list showing that mailbox
   MAY reload when the reader is not using it; one in use (scrolled,
   a row selected, a field focused, not the first page) MUST NOT
   change, and the page offers the refresh instead.
5. Without scripting, a loaded page is current as of its load.

### Presentation

6. htmx swaps MUST NOT run inside a view transition
   (`globalViewTransitions: false`); a swap replaces content without
   animation.
7. Bottom-docked elements pad by `env(safe-area-inset-bottom)`.
8. The manifest's `display` is `minimal-ui`: the browser's address bar
   stays the way out of a page.

## Consequences

- Swipe actions on list rows are not provided.
